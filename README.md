# ДЗ: Биты, байты и побитовые операции

## Что делает программа

1. Строит таблицы истинности для трёх логических выражений.
2. Демонстрирует побитовые операции `&`, `|`, `^`, `~`, `<<`, `>>`.
3. Проверяет тождество дополнительного кода `-x == ~x + 1`.
4. Показывает представление множеств через битовые векторы.
5. Эмулирует переполнение signed / unsigned для 32-битных чисел.

## Запуск

```bash
python dz.py
